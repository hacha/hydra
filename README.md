# Hydra (Fork)

このリポジトリは [hydra-synth/hydra](https://github.com/hydra-synth/hydra) のフォークです。
オリジナルのHydraについての詳細は元リポジトリを参照してください。

**注意**: このforkは個人的に使いやすくするためのカスタマイズを加えたものです。汎用性や互換性よりも、個人の使い勝手を優先して変更を行っています。

## 依存関係

このフォークでは、hydra-synthも変更されたバージョンを使用しています：
- [hacha/hydra-synth](https://github.com/hacha/hydra-synth) - 短縮名の登録など、詳細は該当リポジトリを参照

## キーバインド

このforkで追加されたキーバインド：

| キー | 機能 |
|------|------|
| `Ctrl-A` | オーディオビジュアライザー表示（押している間のみ表示） |
| `Ctrl-V` | o0-o3の出力バッファをプレビュー表示（押している間のみ表示） |
| `Ctrl-T` | タップテンポ（タップしてBPMを計算） |
| `Shift-Ctrl-T` | タップテンポ表示の切り替え |
| `Shift-Ctrl-P` | パフォーマンスセッションの保存 |
| `Shift-Ctrl-M` | セッションリストの表示/非表示 |
| `Shift-Ctrl-Y` | YouTube連携オーバーレイの表示 |

オリジナルから継承されているキーバインド：

| キー | 機能 |
|------|------|
| `Ctrl-Enter` | 現在の行を実行 |
| `Shift-Ctrl-Enter` | すべてのコードを実行 |
| `Alt-Enter` | ブロックを実行 |
| `Ctrl-/` | コメントの切り替え |
| `Shift-Ctrl-H` | UIの表示/非表示 |
| `Shift-Ctrl-F` | コードのフォーマット |

## このフォークでの変更点

### UI関連
- ツールバーを非表示に変更
- トップページアクセス時にランダムスケッチを表示しないように変更
- 閉じるボタンを非表示に変更

### 機能追加

#### 出力プレビュー
- `Ctrl-V`キーでo0-o3の出力バッファをプレビュー表示
- キーを押している間のみ4分割画面で表示される

#### MIDI対応
- WebMIDI APIによるMIDI入力処理を追加
- `window.midi`でグローバルにアクセス可能
- ノート、CC、ピッチベンド、ベロシティに対応

#### MIDIルーパー
マルチトラックのクオンタイズ対応MIDIルーパー。直近60秒のMIDIイベントをリングバッファに自動記録し、ループとして再生できます。

```javascript
// 基本的な使い方
midi.loop('ch1', { bars: 2, bpm: 120 })

// オプション
midi.loop('ch1', {
  bars: 2,           // 録音するバー数（デフォルト: 1）
  playBars: 4,       // 再生時のループ長（デフォルト: barsと同じ）
  beatsPerBar: 4,    // 拍子（デフォルト: 4）
  bpm: 120,          // BPM（省略時はタップテンポの値、なければ120）
  includeCCs: [1,2], // 録音するCC番号（null=全て）
  includeNotes: null, // 録音するノート番号（null=全て）
  excludeNotes: [60], // 除外するノート番号
  quantize: true      // ループ開始をビートにクオンタイズ
})

// ループ長の動的変更
midi.setLoopLength('ch1', 2000) // ミリ秒で指定

// ループ停止
midi.stopLoop('ch1')

// 全リセット
midi.reset()
```

- 複数のループを同時に実行可能（IDで管理）
- 停止したループは再トリガー時に復元される
- 円形ループインジケーターUIで進捗を視覚化

#### タップテンポ機能
- `Ctrl-T`でタップしてBPMを計算
- `Shift-Ctrl-T`で表示の切り替え
- 自動フェードアウト機能
- 計算されたBPMは`bpm`変数でアクセス可能

#### Preloadシステム
URLパラメータでセットアップスクリプトを自動読み込みできます。

- `?preload=example` でスクリプトを読み込み（`.js`拡張子は省略可）
- スクリプトは `/public/preload/` ディレクトリに配置
- セッション録画時にPreload情報も自動保存され、再生時に自動ロードされる

各preloadの詳細はスクリプト先頭のコメントを参照してください。

#### MIDIセッションスナップショット
`midiSnapshot()` を呼ぶと、コード実行を伴わないMIDI操作のみのスナップショットをセッションに記録できます。ハードウェアMIDIパフォーマンスをコード変更の合間に記録する際に有用です。

#### パフォーマンス記録・再生機能
ライブコーディングセッションの記録と再生が可能です。

**自動録画**
- ページロード時に常に自動で録画を開始（操作・パラメータ不要）
- コード実行（`Ctrl-Enter`等）のたびにスナップショットを自動保存
- MIDIイベントもスナップショットに含まれ、再生時に再現される
- タイムスタンプ付きで保存されるため、実行タイミングも再現可能
- `Shift-Ctrl-P`でセッションとして保存（保存しない場合、次回ページロード時に破棄）

**再生**
- `Shift-Ctrl-M`でセッションリストを表示し、任意のセッションを選択して再生
- 再生中は画面右下にコントロールUIを表示
  - 前/次のスナップショットへのスキップボタン
  - 再生/一時停止ボタン
  - 進捗バー（次のスナップショットまでの時間を視覚化）
  - 現在位置/総スナップショット数の表示

**セッション管理**
- セッションはローカルストレージに保存
- セッションリストからエクスポート（JSON）/インポート可能
- 不要なセッションの削除も可能

**URLパラメータ**
- `?preload=<name>` - セットアップスクリプトの自動読み込み（`.js`省略可）
- `?playback=<sessionId>` - 指定セッションを自動再生
- `?playback=<sessionId>&start=<index>&speed=<倍率>` - 開始スナップショット番号（0始まり）と再生速度を指定
- `?session=<url>` - 外部URLからセッションJSONをインポート（CORS対応が必要）

#### YouTube連携機能
セッション記録・再生時にYouTube動画と同期できます。DJ mixなどを流しながらライブコーディングを練習し、後からその音楽と共に再生することを想定しています。

**使い方**
1. `Shift-Ctrl-Y`でYouTubeオーバーレイを表示
2. YouTube URLまたはVideo IDを入力して「Load」をクリック（`?t=`パラメータで開始時間指定可：`?t=2m30s`、`?t=120`等）
3. YouTube動画を再生しながらコーディング（自動録画中）
4. コードを実行するたびに、その時点のYouTube再生位置も自動的に記録される
5. セッション再生時、YouTubeも同期して再生される

**同期機能**
- セッション再生の一時停止/再開 ↔ YouTube動画の一時停止/再開が双方向で同期
- シークバーやスナップショット移動時、YouTube動画も対応する位置にシーク

**注意事項**
- YouTube IFrame Player APIの規約により、プレーヤーは最小200x200pxで表示
- 動画を隠して再生を継続することは規約違反のため、非対応
- 埋め込みが許可されていない動画は再生不可
