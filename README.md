# Hydra (Fork)

このリポジトリは [hydra-synth/hydra](https://github.com/hydra-synth/hydra) のフォークです。
オリジナルのHydraについての詳細は元リポジトリを参照してください。

**注意**: このforkは個人的に使いやすくするためのカスタマイズを加えたものです。汎用性や互換性よりも、個人の使い勝手を優先して変更を行っています。

## 依存関係

このフォークでは、hydra-synthも変更されたバージョンを使用しています：
- [hacha/hydra-synth](https://github.com/hacha/hydra-synth) - 短縮名の登録など、詳細は該当リポジトリを参照

## キーバインド

このforkで追加されたキーバインド：

| キー | 機能 |
|------|------|
| `Ctrl-A` | オーディオビジュアライザー表示（押している間のみ表示） |
| `Ctrl-V` | o0-o3の出力バッファをプレビュー表示（押している間のみ表示） |
| `Ctrl-T` | タップテンポ（タップしてBPMを計算） |
| `Shift-Ctrl-T` | タップテンポ表示の切り替え |

オリジナルから継承されているキーバインド：

| キー | 機能 |
|------|------|
| `Ctrl-Enter` | 現在の行を実行 |
| `Shift-Ctrl-Enter` | すべてのコードを実行 |
| `Alt-Enter` | ブロックを実行 |
| `Ctrl-/` | コメントの切り替え |
| `Shift-Ctrl-H` | UIの表示/非表示 |
| `Shift-Ctrl-F` | コードのフォーマット |

## このフォークでの変更点

### UI関連
- ツールバーを非表示に変更
- トップページアクセス時にランダムスケッチを表示しないように変更
- 閉じるボタンを非表示に変更

### 機能追加

#### 出力プレビュー
- `Ctrl-V`キーでo0-o3の出力バッファをプレビュー表示
- キーを押している間のみ4分割画面で表示される

#### MIDI対応
- WebMIDI APIによるMIDI入力処理を追加
- `window.midi`でグローバルにアクセス可能
- ノート、CC、ピッチベンド、ベロシティに対応

#### タップテンポ機能
- `Ctrl-T`でタップしてBPMを計算
- `Shift-Ctrl-T`で表示の切り替え
- 自動フェードアウト機能
- 計算されたBPMは`bpm`変数でアクセス可能

#### 解像度設定
- デフォルト解像度を1920x1080に変更
- 環境変数による解像度設定のサポート

### hydra-strudel拡張
- デフォルトでhydra-strudel拡張を適用

### 開発環境
- 開発時はローカルのhydra-synthファイルを参照するように設定
- 開発環境と本番環境でbaseパスを適切に切り替え
- 環境変数による設定の柔軟化

### ビルド・デプロイ
- GitHub Pages対応
- baseパスを/hydra/に設定（本番環境）
- 末尾スラッシュの有無両方に対応するルーティング設定
- gh-pagesパッケージを追加してデプロイ方法を改善
- distディレクトリをmainブランチから削除
- ビルド設定の改善

### Docker対応
- Docker Composeによるコンテナ化を実装
- 開発環境と本番環境の両方に対応

## ビルドコマンド

```bash
# 開発サーバー（http://localhost:5173）
npm run dev

# 本番ビルド
npm run build

# GitHub Pagesへデプロイ
npm run publish
```
